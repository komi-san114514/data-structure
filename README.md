## 1. scanf 的宽度数字含义（宽度限制）

scanf("%13s %60s %lf", book.number_book, book.name_book, &book.price) != EOF（注：这里的book.number_book, book.name_book均为char类型的数组，且前者大小为14，后者大小为61）
`%Ns`：**最多读取 N 个字符**，然后自动在末尾补`\0`字符串结束标记。
👉 `\0` 会占用**1 个位置**，所以 N 必须 ≤ 数组长度 - 1

- `number[14]` → 最多安全读 **13 个字符** → `%13s`
你写了`%14s`：

> 
> 最多读 14 个字符，再加`\0`，总共需要 15 字节，但是数组只有 14 字节！**缓冲区溢出！**

- `name[30]` → 最多安全读 **29 个字符** → `%29s`
你写`%30s`：读 30 字符 + `\0`，需要 31 字节，数组只有 30 字节，**溢出**
